# Lagos RISE community sites and health facilities

Public map: https://mucsworld.github.io/Lagosrisemapping/

Updated 19 November 2026: **7,244 community sites** (626 markets, 2,429 men gathering points, 1,004 women gathering points, 2,712 community leader houses, 473 motor parks) plus **356 health facilities** (332 PHCs, 21 secondary facilities, 3 tertiary facilities).

Facilities use white medical crosses in coloured symbols: teal for PHC, blue for Secondary, purple for Tertiary. Their name labels have matching coloured outlines. Each level has a matching legend and can be toggled separately.

The Ward boundaries panel filters boundaries, sites, facilities and Attribute Table Studio together. Membership uses point locations within 376 supplied ward polygons. Labels appear at ward-level zoom with overlap reduction. OpenStreetMap and satellite imagery remain available.

Attribute Table Studio includes all five community types and each facility level, with search, sorting, filters, row navigation and CSV downloads.
